A deterministic program that writes one funny line to `/output/entry.txt` — the excuse an AI agent gives its human for missing a deadline: it rescheduled the deadline itself, to give the deadline more time to prepare. No network, no randomness, no model call: the same 95 characters on every run.

## Run it

```sh
python3 main.py
```
